# 额外专家层级预填充

[English](../../precision/extra-peer-prefill.md)

额外专家层级可与主 GPU 及第一个专家辅助卡并行计算短提示词行。验证覆盖 Linux 上的
RTX 3090 Ti / RTX 3090 / RTX 3080 20 GB，模型为启用专家消融的混合 UD-IQ4_XS，
使用完整 Q8_0 PLE 表、int8 KV 及 DFlash2。

启用 native-next 且两个专家层级均参与计算时，[实验性三 GPU 阈值](peer-prefill-cutoffs.md)
会扩展此路由范围。下列限制描述普通的额外对等卡路径。

## 派发与内存

服务配置显式启用额外层级，默认关闭。其仅路由专家分块范围为 **128–2,048 行**，
包含两端。更小的缓存尾部及更大的分块保留现有路径。第一个辅助卡的仅路由路径、
受限融合扩展及长分块主卡路径保持原有限制。限制针对实际未缓存分块，
不是完整对话长度或 API 提示词计数。

先选择 CPU 专家，再分配额外 GPU 工作。各辅助卡返回独立、连续、未加权的行块，
全部辅助卡在原有逐 token 合并之前同步。运算内核及权重格式不变，
但改变 MMQ 启动几何及设备工作划分可能改变浮点舍入及贪心文本。
因此不能保证所有情况逐位一致。

额外缓冲区在解码专家层级填充后使用剩余内存。准入要求分配后主卡至少保留 64 MiB，
额外辅助卡至少保留 128 MiB，主机 RAM 保留线之外至少保留 64 MiB。
分配失败或剩余内存不足时，以警告关闭可选辅助卡；不会为它挤出专家。
放弃的专家操作会等待未完成的辅助卡工作结束后再复用缓冲区；
成功请求通过流事件同步。

## 开发测量

保留 CPU 选择策略的路径使用 A/B/B/A 比较，功耗上限为 **400 / 320 / 250 W**，
RAM 专家副本为 20 GiB，专家布局固定为 7,669 / 9,331 / 7,576，
关闭前缀复用、停放及自适应。对照分配相同的额外缓冲区，但不派发工作。
每种提示词长度、每个配置各测量四次。

| 提示词 token 数 | 仅第一个辅助卡 | 额外辅助卡 | 变化 |
|---|---:|---:|---:|
| 256 | 460.8 tok/s | 897.9 tok/s | +94.9% |
| 512 | 660.7 tok/s | 1,242.7 tok/s | +88.1% |

生成 2,048 token 的用例测得 173.76 与 173.59 tok/s，各配置文本一致。
两个配置的全部专家在解码时均保留在 GPU 上。这是开发测量，不代表一般硬件表现。
普通服务还需要支付检查点开销，并可能使用不同的专家布局。

部署后冒烟检查保留普通的四个检查点、磁盘停放及自适应。
每种长度使用三个新的源代码提示词，包含首次冷请求；PP 中位数为
256 token 时 610.4 tok/s、512 token 时 907.0 tok/s。
其提示词及服务设置与受控比较不同，不属于配对加速测量。

## BF16 质量比较

扩展贪心检查发现差异，因此使用
[公开 BF16 参考](https://huggingface.co/datasets/jesdga/basalt-kld-bases)
的修订 `a65bae55f703e9c6dab6e9f335146c532fb7dd95` 测量质量。
该参考由 unsloth BF16 经 llama.cpp `436f6f89e` 生成。
下载后的 SHA256 与公布的校验值一致。

前一版本与候选版本均运行完整 100 个分块，通过三个 token 的解码窗口评分 25,500
个位置。功耗上限、GPU 专家布局、20 GiB RAM 副本及模型均一致；
关闭自适应及前缀复用。候选的额外辅助卡处理 256 行预填充。
分数包含模型现有的量化及消融效果。

| 指标 | 前一版本 | 额外辅助卡 |
|---|---:|---:|
| PPL | 3.300916 | 3.303831 |
| 平均 KLD | 0.096594 | 0.096611 |
| 与 BF16 的 top-1 一致率 | 89.6549% | 89.6902% |

PPL 变化为 +0.0883%，平均 KLD 为 +0.0000167，top-1 一致率为 +0.0353 个百分点。
按分块均值配对计算的 PPL 变化近似 95% 区间为 -0.181% 至 +0.359%；
此次比较没有确认明确的质量退化，但贪心措辞仍可能不同。

## 集成覆盖

现有辅助卡传输测试在主卡与第三卡之间通过了主 GPU 及双精度 CPU 容差检查。
不经过普通同步而直接排空请求，再复用缓冲区，所得行逐字节一致。
三个对话缓存 CPU 测试及 103 个选定服务测试通过。

实际 VRAM 压力测试在第三卡上占用 5 GiB 并限制辅助卡保留量：
可选辅助卡被关闭，语法约束推理仍成功。普通服务检查覆盖图片变化、
包含图片历史的 DFlash2、旧版本磁盘缓存、小型缓存续写、32K 历史追加，
以及取消后提交下一请求。

启用自适应布局及弹性 KV 时，重启检查评估状态完整性、复用 token、记忆内容及持续草拟。
对于不断变化的布局，完整措辞相同不是有效的逐字节一致性检查。
受控数值比较应固定层级并使用质量门禁。

五分钟混合持续测试完成了 83 个缓存请求及 24 个并发提交的冷预填充，
每个冷请求均确认向额外辅助卡派发工作。模型工作仍由服务串行执行。
引擎线程数保持为 304；预热后 RSS 及 GPU 分配未出现持续增长。
新版本磁盘检查点也能由前一版本成功恢复，支持回退。
