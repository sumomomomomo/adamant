# 预算内的重叠预填充 RAM 后备副本

[English](../../precision/budgeted-prefill.md)

使用批处理槽位和显式常驻 RAM 预算时，提示词工作区借用主 GPU 专家缓存的一段连续尾部。
这些专家权重必须有 RAM 副本，才能在另一槽位解码期间恢复，而无需读取文件。

## 选择与容量

模型按照 1,024-token 提示词分块，以及各槽位增长到一个配置预填充分块长度时估算的 KV
增量，计算后备区域。该区域受普通提示词借用区域限制。预算加载器优先为自适应交换的
空闲位置和缓存尾部副本分配空间，再用剩余预算按热度选择专家。
副本和空闲位置的总和不超过请求的 RAM 预算。

只有完整专家组成的连续尾部才计入后备容量。遇到无法容纳的专家时停止扩展尾部；
不同专家大小分别计算。未指定预算的完整补集路径保持不变。

`--read-live-chunk` 同样限制后台重叠读取路径，默认 1,024 个 token。
KV 增长会减少剩余借用容量，因此可能选择更小分块。调度器在借用前检查当前 RAM 所有权。
自适应提升不能用没有 RAM 副本的专家替换受保护尾部的权重。
短提示词保留现有的独占读取调度，除非启用 `--read-beside`。

此改动改变 RAM 选择策略，不改变权重格式或运算内核。选择和分块可能改变实际执行的
CPU/GPU 运算，因此贪心输出可能变化。此改动不会消除长上下文准入或工作区设置时的停顿。

## 开发验证

正常内存分配的服务测试使用 RTX 3090 Ti / RTX 3090 / RTX 3080，强制功耗上限为
400 / 320 / 250 W，配置 int8 KV、MTP 窗口 8、Q8_0 PLE、两个 262,144-token 槽位、
22.9 GiB 常驻 RAM 预算、32,768-token 预填充容量和额外预填充对等卡。
嵌入服务运行在 CPU 上。这些是代理开发测量，不是宣传基准，也不是独立内核计时。

两个候选版本请求前后分别运行旧版本，总计四个旧版本请求。每次使用相同的未缓存
21,305-token 提示词，同时另一槽位生成 4,096 个 token。

| 指标 | 改动前 | 改动后 |
|---|---:|---:|
| 普通重叠分块 | 256 token | 1,024 token |
| 预填充时间范围 | 31.30–34.46 s | 22.72–26.25 s |
| 预填充时间中位数 | 33.34 s | 24.48 s |
| 并发解码时间中位数 | 18.22 s | 18.38 s |
| 各次最大流式输出间隔的范围 | 0.256–0.691 s | 0.414–0.462 s |

预填充延迟中位数下降 26.6%。解码差异相对于这几次运行的波动较小，
但这不能证明解码完全没有代价。

另一组配对压力测试为两个槽位提供约 21K-token 提示词。随着 KV 存储占用缓存空间，
候选版本使用 768-token 分块。第二次预填充耗时从 33.29 秒降至 25.41 秒。
两个版本均保留长上下文设置停顿：改动后观测到的最大输出间隔为 5.61 秒，改动前为
5.14 秒。请求均正常完成。候选版本日志显示被 KV 驱逐的专家均有 RAM 副本，
启动时没有仅存于文件的专家。

`file_expert_budget_lend_test` 检查不同大小的专家、部分预算、交换空闲位置、锁页和普通
内存副本、重复及无效热度条目，以及未改变的完整补集选择。测试覆盖借出的 GPU 槽位，
然后验证从 RAM 恢复的权重逐字节相同。现有来源、RAM 位置和重新锁页测试均通过。
实际服务检查覆盖启用正常自适应调整时的取消、恢复，以及两个并发解码器。

标准单活跃槽位基准使用相同的普通分配配置及功率限制，并禁用自适应。
这些顺序运行的开发测试作为辅助检查，不是固定专家布局下的性能结论。

| 解码样例 | 变更前 ms/窗口（pass/s） | 变更后 ms/窗口（pass/s） |
|---|---:|---:|
| 对话 | 21.0796 (47.4393) | 21.1587 (47.2620) |
| 结构化 | 34.3183 (29.1390) | 34.3670 (29.0977) |
| 散文 | 19.7031 (50.7535) | 19.7237 (50.7004) |

在上述功率限制下，未缓存的独立预填充在 4K 时为 1,565.32 → 1,666.00 tok/s，
在 16K 时为 2,134.20 → 2,240.68 tok/s。

完整 BF16 参考解码质量检查使用 100 个分块、25,500 行，MTP 窗口为 5，
RAM 预算及 GPU 功率限制相同，禁用自适应。
保持普通分配，因此专家布局及算术路径可能不同。

| 质量指标 | 变更前 | 变更后 |
|---|---:|---:|
| PPL（BF16 参考值 3.27327） | 3.30101 | 3.30548 |
| 平均 KLD | 0.0969211 | 0.0964061 |
| Top-1 一致率 | 89.7647% | 89.8471% |

PPL 的小幅增加处于报告的约 0.043 采样误差以内；
KLD 与 top-1 未出现相应退化。数值结果并非逐位相同。

部署冒烟验证使用较低的 22.0 GiB 预算，因为实际服务的 RAM 安全检查允许的
余量少于基准进程。两个槽位均处理请求，重叠预填充使用 1,024-token 分块，
因 KV 增长被移出的专家均有 RAM 副本；启动日志及指标接口均报告零 SSD 溢出。
